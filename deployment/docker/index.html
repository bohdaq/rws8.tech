Docker

Prebuilt image

Section titled “Prebuilt image”

Every release publishes a multi-arch image (linux/amd64, linux/arm64) to Docker Hub as bohdaq/rws and to the GitHub Container Registry as ghcr.io/bohdaq/rws, tagged with the full version (17.113.0), the major version (17), and latest:

The image is gcr.io/distroless/static-debian12:nonroot plus the static musl rws binary (about 12 MB) — no shell, no package manager, runs as a non-root user. The working directory is /srv: mount static content there, or put an rws.config.toml there to run as a config-driven proxy. Configure with RWS_CONFIG_* environment variables, e.g. -e RWS_CONFIG_PORT=8080. Each release image is started and checked (/healthz, the served page, --version) before it’s published.

Automatic HTTPS in Docker

Section titled “Automatic HTTPS in Docker”

rws writes the Let’s Encrypt certificate, its key and the ACME account key to /data (owned by the image’s user). Mount a volume there so restarts reuse the certificate instead of requesting a new one:

with an [acme] section in the mounted rws.config.toml (see Automatic HTTPS). 443/udp carries HTTP/3.

Build your own image with the Dockerfile below if you need non-default Cargo features or your own application code.

Multi-stage Dockerfile

Section titled “Multi-stage Dockerfile”

The recommended Dockerfile uses a two-stage build: a rust:1.99 builder compiles the binary, then a slim Debian image carries only the final executable.

Dependency cache layer

The dummy src/main.rs trick builds and caches all Cargo dependencies before the real source is copied. Subsequent builds that only change application code skip the full cargo build of your dependencies.

Image sizes by feature flag

Section titled “Image sizes by feature flag”

The default cargo build --release enables the http3 feature, which includes QUIC, HTTP/2, TLS (rustls), and the quinn/h3 stacks. Lighter builds are available:

Feature flag TLS HTTP/2 HTTP/3 Approx. final image
http1 (no-default) No No No ~3 MB
http2 (no-default) Yes (rustls) Yes No ~7 MB
http3 (default) Yes (rustls) Yes Yes ~12 MB

Exposed ports

Section titled “Exposed ports”
Port Protocol Purpose
7878 TCP HTTP/1.1 and HTTP/2 (TLS upgrade via ALPN)
7878/udp UDP HTTP/3 / QUIC (only active when a TLS cert is configured)

Change the port at runtime with RWS_CONFIG_PORT.

SIGHUP hot-reload inside Docker

Send docker kill --signal=SIGHUP <container> to reload TLS certificates, CORS rules, rate limits, and log format without restarting the container. The server’s /admin/config/reload endpoint does the same over HTTP.
