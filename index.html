What’s inside

Section titled “What’s inside”

Automatic HTTPS

Built-in ACME client: Let’s Encrypt or a private CA, HTTP→HTTPS redirects, background renewal with hot reload, IPv4 and IPv6.

Reverse proxy & gateway

Load balancing, health checks, bearer / JWT / basic auth that fails closed, rate limits, caching, rewrites, IP filters — plus TCP, UDP, WebSocket, and gRPC proxying.

One TOML file

Every setting lives in rws.config.toml (or env vars, or flags). Unknown keys are reported at startup instead of silently ignored.

No hyper, no Tower, no OpenSSL

HTTP/1.1, HTTP/2, routing, middleware, WebSocket, SSE, and the ACME client are implemented in-crate. HTTP/3 uses quinn; TLS uses rustls.

Kubernetes-ready

/healthz, /readyz, Prometheus /metrics, graceful SIGTERM shutdown, and a Kubernetes Ingress watcher.

MCP server

Expose tools, resources, and prompts to Claude and other AI agents over MCP Streamable HTTP with a builder API.

Need custom logic? It’s a Rust library

Section titled “Need custom logic? It’s a Rust library”

The server above is the rust-web-server crate. Use it directly for routes, middleware, an MCP server, an ORM, background jobs, and more:

One middleware trait

Auth, rate limiting, caching, tracing, rewriting, and the reverse proxy itself share one handle(request, connection, next) signature.

Model layer ORM

#[derive(Model)], a type-safe QueryBuilder, migrations, and relations — SQLite, PostgreSQL, or MySQL.

Login & auth

OAuth 2.0 / OIDC (“Login with Google”), SAML 2.0, its own OAuth authorization server, sessions, CSRF.

In-process test client

TestClient::new(app) dispatches requests without opening a socket — fast, hermetic tests.
